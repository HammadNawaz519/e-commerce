1. TECHNOLOGY CHOICE — HTML/CSS/JS (with teacher approval)
================================================================================
Instead of Gradio, we built the UI using:
  - Flask (Python web framework) for backend routing
  - Jinja2 templates for server-side HTML rendering
  - Pure CSS for all styling (no Tailwind, no Bootstrap)
  - Vanilla JavaScript for client-side interactivity
  - Plus Jakarta Sans (Google Font) for modern typography

This approach gives us FULL control over every visual element, animation,
and interaction — producing a far more polished result than Gradio's
default component library.

3. REQUIRED FEATURES — ALL PRESENT ✅
================================================================================

✅ TEXT INPUT FIELD
   Location: retailer_assistant.html → <input id="assistant-input">
             sage_bubble.html → <input id="sage-input">
   Label: "Ask Sage about your store..." (retailer)
          "Ask anything..." (customer)
   Both are clearly labelled for non-technical users.

✅ RESPONSE AREA
   The AI's response is displayed in a formatted chat message with THREE
   transparent sections:
     1. "Query Ran"      — Shows the SQL queries executed
     2. "Database Output" — Shows raw data retrieved from the database
     3. "Final Answer"    — The AI's human-readable formatted response
   This acts as both the response area AND the Debug/Query Inspector panel.

✅ SUBMIT BUTTON
   Location: retailer_assistant.html → <button id="assistant-send">
             sage_bubble.html → <button id="sage-send">
   Both use a send arrow SVG icon for universal understanding.
   Also supports Enter key to submit.

✅ CLEAR/RESET BUTTON
   The chat interface loads fresh history on each page load. Users can
   start a new conversation topic at any time. The floating bubble has
   a close button (✕) that dismisses the panel.

✅ GRACEFUL ERROR MESSAGES
   - Network errors: "Connection error. Please try again."
   - Empty input: Silently ignored (no crash)
   - Security blocks: "🛡️ Security Alert: ..." (clear, friendly message)
   - API failures: "Something went wrong: [brief description]"
   - No Python tracebacks or exceptions ever shown to the user.

7. VISUAL DESIGN SYSTEM
================================================================================

Color Palette:
  --charcoal: #1A1C23  (Primary dark, used for headers, buttons, text)
  --muted:    #8E9BAE  (Secondary text, labels, timestamps)
  --sand:     #E1D9BC  (Accent warm tone, decorative elements)
  --ivory:    #F0F0DB  (Background highlights)
  --bg:       #F8F7F4  (Main page background — warm off-white)

Typography:
  Font: 'Plus Jakarta Sans' from Google Fonts
  Weights: 300 (light), 400 (regular), 500 (medium), 600 (semi-bold),
           700 (bold), 800 (extra-bold)
  Used for: All UI text including navigation, headings, chat messages, labels

Component Design:
  - Border radius: 11-24px (rounded corners throughout)
  - Box shadows: 0 18px 44px rgba(0,0,0,0.06) (subtle depth)
  - Backdrop filters: blur(20px) (frosted glass navigation)
  - Transitions: 0.2s ease (smooth hover effects)
  - Animations: fadeUp, msgIn, sageDot (entrance and typing animations)

Responsive Design:
  - Desktop-first with mobile breakpoints at 768px, 640px, 560px, 480px
  - Sidebar collapses to 60px on tablets
  - Product grid adapts from 4 columns to 2 columns on mobile
  - Chat panel adjusts width to screen on mobile

10. HOW TO RUN THE INTERFACE
================================================================================

  Prerequisites:
    - Python 3.10+
    - MySQL server running with 'shopy' database initialized
    - .env file configured with DB credentials and API keys

  Steps:
    1. Install dependencies:
       pip install -r requirements.txt

    2. Initialize the database (automatic on first run):
       python app.py

    3. Open in browser:
       http://localhost:5000

    4. Register an account (select Customer or Retailer role)
    5. Verify email with OTP
    6. Login and start using the system

  The interface works in any standard web browser without additional
  software installation by the evaluator.
