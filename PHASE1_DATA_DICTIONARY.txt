SHOPY PHASE 1 DATA DICTIONARY
Course: CS-254 Database Systems
Database: shopy
Source Schema: shopy.sql

Legend:
PK = Primary Key
FK = Foreign Key
NN = NOT NULL
UQ = UNIQUE
DEF = Default value
AI = AUTO_INCREMENT

============================================================
TABLE: users
============================================================
id | INT | PK, NN, AI | Unique identifier for each user account.
username | VARCHAR(80) | NN | Display name used across storefront and profile screens.
phone_number | VARCHAR(30) | Nullable | Contact number for account holder.
email | VARCHAR(120) | NN, UQ | Unique email for authentication and verification.
password | VARCHAR(256) | NN | Hashed password credential.
verified | TINYINT(1) | NN, DEF 0 | Email verification status flag.
role | VARCHAR(20) | NN, DEF 'customer' | Role of user (customer or retailer).
profile_pic | TEXT | Nullable | URL/path of profile image.
bio | TEXT | Nullable | User profile description text.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Account creation timestamp.
updated_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | Last update timestamp.

============================================================
TABLE: categories
============================================================
id | INT | PK, NN, AI | Unique identifier for each product category.
name | VARCHAR(100) | NN, UQ | Category name shown to users.
slug | VARCHAR(120) | Nullable, UQ | URL-safe category token.
description | VARCHAR(255) | Nullable | Short category summary.
is_active | TINYINT(1) | NN, DEF 1 | Category active/inactive status.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Category creation timestamp.
updated_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | Last category update time.

============================================================
TABLE: products
============================================================
id | INT | PK, NN, AI | Unique product identifier.
retailer_id | INT | NN, FK -> users.id | Retailer who owns and sells the product.
category_id | INT | Nullable, FK -> categories.id | Category assigned to product.
name | VARCHAR(200) | NN | Product title visible in listings.
description | TEXT | Nullable | Detailed product description.
price | DECIMAL(10,2) | NN | Current selling price.
original_price | DECIMAL(10,2) | Nullable | Previous/list price for discount display.
stock | INT | NN, DEF 0 | Current inventory units available.
image_url | TEXT | Nullable | Primary image URL shown in catalog.
sku | VARCHAR(80) | Nullable, UQ | Internal stock keeping unit code.
weight_grams | INT | Nullable | Shipping and logistics weight in grams.
is_active | TINYINT(1) | NN, DEF 1 | Visibility status in store.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Product creation timestamp.
updated_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | Last product update timestamp.

============================================================
TABLE: product_images
============================================================
id | INT | PK, NN, AI | Unique gallery image identifier.
product_id | INT | NN, FK -> products.id | Product mapped to this image.
image_url | TEXT | NN | URL/path of product image file.
alt_text | VARCHAR(180) | Nullable | Accessibility/SEO alternate text.
sort_order | INT | NN, DEF 1 | Display order inside product gallery.
is_primary | TINYINT(1) | NN, DEF 0 | Marks image as primary product image.
uploaded_by_user_id | INT | Nullable, FK -> users.id | User who uploaded this image.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Upload creation timestamp.

============================================================
TABLE: discount_codes
============================================================
id | INT | PK, NN, AI | Unique discount code identifier.
code | VARCHAR(50) | NN, UQ | Redeemable coupon code token.
campaign_name | VARCHAR(120) | Nullable | Marketing campaign label for coupon.
discount_type | VARCHAR(20) | NN, DEF 'percent' | Discount mode (percent or fixed).
discount_value | DECIMAL(10,2) | NN | Numeric discount amount/value.
min_order_value | DECIMAL(10,2) | NN, DEF 0 | Minimum cart total to apply discount.
max_uses | INT | Nullable | Max allowed redemption count.
uses_count | INT | NN, DEF 0 | Current redemption count.
expires_at | DATETIME | Nullable | Coupon expiration date/time.
is_active | TINYINT(1) | NN, DEF 1 | Active/inactive coupon status.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Coupon creation timestamp.

============================================================
TABLE: addresses
============================================================
id | INT | PK, NN, AI | Unique saved address identifier.
user_id | INT | NN, FK -> users.id | User owning this saved address.
label | VARCHAR(50) | NN, DEF 'Home' | Address label (Home/Office/etc.).
full_name | VARCHAR(100) | Nullable | Recipient full name for shipment.
phone | VARCHAR(30) | Nullable | Recipient phone for delivery contact.
address_line | TEXT | NN | Street and house/apartment details.
city | VARCHAR(100) | Nullable | City name.
province | VARCHAR(100) | Nullable | Province/state name.
postal_code | VARCHAR(20) | Nullable | Postal/ZIP code.
country | VARCHAR(100) | NN, DEF 'Pakistan' | Country name.
is_default | TINYINT(1) | NN, DEF 0 | Marks this as default shipping address.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Address creation timestamp.

============================================================
TABLE: orders
============================================================
id | INT | PK, NN, AI | Unique order identifier.
customer_id | INT | NN, FK -> users.id | Customer placing the order.
total_amount | DECIMAL(10,2) | NN | Final order total payable.
status | VARCHAR(30) | NN, DEF 'pending' | Fulfillment lifecycle status.
shipping_name | VARCHAR(100) | Nullable | Recipient name at delivery address.
shipping_address | TEXT | Nullable | Full shipping destination text.
shipping_phone | VARCHAR(30) | Nullable | Contact number for courier.
notes | TEXT | Nullable | Additional order notes/instructions.
discount_code_id | INT | Nullable, FK -> discount_codes.id | Applied coupon reference.
discount_amount | DECIMAL(10,2) | NN, DEF 0 | Total discount deducted from order.
payment_method | VARCHAR(30) | NN, DEF 'cod' | Payment method selected by customer.
payment_status | VARCHAR(20) | NN, DEF 'pending' | Payment state (pending/paid/refunded).
payment_ref | VARCHAR(64) | Nullable | External payment reference ID.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Order creation timestamp.
updated_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | Last order update timestamp.

============================================================
TABLE: order_items
============================================================
id | INT | PK, NN, AI | Unique line-item identifier.
order_id | INT | NN, FK -> orders.id | Parent order containing this line item.
product_id | INT | Nullable, FK -> products.id | Purchased product reference.
retailer_id | INT | Nullable, FK -> users.id | Retailer associated with this item.
product_name | VARCHAR(200) | Nullable | Snapshot name of product at purchase time.
quantity | INT | NN | Units purchased for this item line.
unit_price | DECIMAL(10,2) | NN | Price per unit at checkout.
discount_per_unit | DECIMAL(10,2) | NN, DEF 0 | Per-unit discount applied.

============================================================
TABLE: cart
============================================================
id | INT | PK, NN, AI | Unique cart row identifier.
user_id | INT | NN, FK -> users.id | Customer owning this cart entry.
product_id | INT | NN, FK -> products.id | Product currently in cart.
quantity | INT | NN, DEF 1 | Quantity selected in cart.
added_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Timestamp when item was first added.
updated_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | Last quantity/update time.

============================================================
TABLE: wishlists
============================================================
id | INT | PK, NN, AI | Unique wishlist row identifier.
user_id | INT | NN, FK -> users.id | Customer owning this wishlist entry.
product_id | INT | NN, FK -> products.id | Product saved for future purchase.
priority | TINYINT | NN, DEF 3, CHECK 1..5 | User-defined importance ranking.
target_price | DECIMAL(10,2) | Nullable | Desired price threshold for purchase.
notify_on_price_drop | TINYINT(1) | NN, DEF 0 | Notification preference for price drops.
note | VARCHAR(255) | Nullable | User note attached to wishlist item.
added_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Timestamp of wishlist insertion.

============================================================
TABLE: reviews
============================================================
id | INT | PK, NN, AI | Unique review identifier.
product_id | INT | NN, FK -> products.id | Product being reviewed.
user_id | INT | NN, FK -> users.id | User posting the review.
rating | INT | NN, CHECK 1..5 | Numeric rating score.
title | VARCHAR(120) | Nullable | Short headline for review.
comment | TEXT | Nullable | Written review body.
is_verified_purchase | TINYINT(1) | NN, DEF 0 | Indicates verified purchase origin.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Review creation timestamp.

============================================================
TABLE: ai_chat_history
============================================================
id | INT | PK, NN, AI | Unique chat history record identifier.
user_id | INT | NN, FK -> users.id | User associated with this conversation message.
role | VARCHAR(20) | NN, DEF 'customer' | App role context for conversation (customer or retailer).
sender | ENUM('user','bot') | NN | Message origin in the conversation.
message | TEXT | NN | Stored chat message content.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Chat message creation timestamp.

============================================================
TABLE: notifications
============================================================
id | INT | PK, NN, AI | Unique notification identifier.
user_id | INT | NN, FK -> users.id | User receiving this notification.
message | TEXT | NN | Notification message content.
type | VARCHAR(50) | NN, DEF 'info' | Notification category (order/promo/info).
channel | VARCHAR(30) | NN, DEF 'in_app' | Delivery channel (in-app/email/sms).
action_url | VARCHAR(255) | Nullable | Optional link for user action.
is_read | TINYINT(1) | NN, DEF 0 | Read/unread state flag.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Notification creation timestamp.

============================================================
TABLE: payments
============================================================
id | INT | PK, NN, AI | Unique payment record identifier.
order_id | INT | NN, FK -> orders.id | Order associated with this payment.
payment_method | VARCHAR(30) | NN | Mode of payment used.
provider | VARCHAR(40) | Nullable | Payment gateway/provider name.
amount_paid | DECIMAL(10,2) | NN | Amount actually paid for transaction.
payment_status | VARCHAR(20) | NN, DEF 'pending' | Payment processing state.
transaction_ref | VARCHAR(120) | Nullable | External transaction reference.
paid_at | DATETIME | Nullable | Timestamp when payment succeeded.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Payment record creation timestamp.

============================================================
TABLE: shipments
============================================================
id | INT | PK, NN, AI | Unique shipment record identifier.
order_id | INT | NN, FK -> orders.id | Order tied to shipment.
courier_name | VARCHAR(80) | NN | Courier service provider name.
tracking_number | VARCHAR(120) | Nullable, UQ | Shipment tracking identifier.
shipment_status | VARCHAR(20) | NN, DEF 'pending' | Shipment lifecycle status.
shipped_at | DATETIME | Nullable | Actual dispatch timestamp.
expected_delivery | DATETIME | Nullable | Estimated delivery time.
delivered_at | DATETIME | Nullable | Confirmed delivered timestamp.
shipping_cost | DECIMAL(10,2) | NN, DEF 0 | Delivery/logistics cost amount.
created_at | TIMESTAMP | NN, DEF CURRENT_TIMESTAMP | Shipment record creation timestamp.

============================================================
RELATIONSHIP SUMMARY (CARDINALITY)
============================================================
users (1) -> (many) products via products.retailer_id
categories (1) -> (many) products via products.category_id
products (1) -> (many) product_images via product_images.product_id
users (1) -> (many) product_images via product_images.uploaded_by_user_id
users (1) -> (many) addresses via addresses.user_id
users (1) -> (many) orders via orders.customer_id
discount_codes (1) -> (many) orders via orders.discount_code_id
orders (1) -> (many) order_items via order_items.order_id
products (1) -> (many) order_items via order_items.product_id
users (1) -> (many) order_items via order_items.retailer_id
users (1) -> (many) cart via cart.user_id
products (1) -> (many) cart via cart.product_id
users (1) -> (many) wishlists via wishlists.user_id
products (1) -> (many) wishlists via wishlists.product_id
products (1) -> (many) reviews via reviews.product_id
users (1) -> (many) reviews via reviews.user_id
users (1) -> (many) ai_chat_history via ai_chat_history.user_id
users (1) -> (many) notifications via notifications.user_id
orders (1) -> (many) payments via payments.order_id
orders (1) -> (many) shipments via shipments.order_id
